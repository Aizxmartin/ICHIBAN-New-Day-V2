# PDF handling notes for real estate inputs

This note preserves the current working guidance for ICHIBAN users who need to review, search, or prepare PDFs before upload.

## Fastest no-account PDF review

Use **Google Chrome** or **Microsoft Edge** first. Drag the PDF directly onto a browser tab. This usually allows:

- clean visual rendering
- scrolling and zooming
- Ctrl+F search
- text selection/copy when the PDF has embedded text

This is often smoother than opening MLS/property PDFs through Word.

## Free PDF readers

- Microsoft Edge: built into Windows, good PDF reading, highlighting, and search.
- Google Chrome / Chromium browsers: easy drag-and-drop PDF viewing.
- Adobe Acrobat Reader: free for reading; paid features are mainly for editing.

## If the PDF must be reorganized or converted

Useful no/low-friction tools include Adobe Acrobat online, Smallpdf, and iLovePDF for merge/split/compress/convert-to-Word workflows. Use these carefully with confidential documents.

## ICHIBAN parser preference

For 1004MC and MLS/property support files, prefer the direct system PDF export/download when available.

Avoid **Microsoft Print to PDF** when possible because it can create image-only or layout-damaged PDFs. Image-only PDFs may require OCR or manual entry.

## Realtor workflow reminder

Before assuming ICHIBAN failed, open the PDF in Chrome or Edge and test:

1. Can you highlight/select text?
2. Does Ctrl+F find words visible on the page?
3. Are tables rendered as text or only as a picture?

If text cannot be selected or searched, treat the file as image-like and use the manual/verification fallback path.
